Section 02

Platform Overview

Axon Tickets is a complete event ticketing solution — it covers everything from creating an event and setting ticket prices, to processing payments, delivering digital tickets to attendees, and scanning QR codes at the door on event day. There are two sides to the platform:

🎪 For Attendees

  • Browse and discover events
  • Purchase tickets online (credit/debit, GCash, Maya)
  • Receive QR-coded ticket by email
  • View past orders and ticket history
  • Register with Google or email

🎛️ For Organizers (Admin)

  • Create and manage events with rich details
  • Set multiple ticket tiers and pricing
  • Manage speakers, sponsors, FAQs, and agenda
  • Monitor real-time ticket sales and orders
  • Scan QR codes for check-in on event day
  • Resend tickets to attendees

What sets Axon Tickets apart is that it was designed specifically for conferences and speaker-led events — not just concerts. Features like speaker profiles, session agendas, sponsor tiers, and FAQ management are built directly into the platform. This is not available in most Philippine competitors.

Section 07

Technology Foundation

Axon Tickets is built on proven, industry-standard technology used by companies like Netflix, Airbnb, and major Philippine fintechs. The platform is designed to be reliable, fast, and secure — without being over-engineered for the current stage.

Website (Front-End)
Built with Next.js — the same framework used by TikTok, Twitch, and Lazada. Delivers fast page loads, works well on mobile data, and is optimized for Philippine internet speeds. Hosted on Vercel — a globally distributed network that automatically scales with traffic.
Back-End & Database
Built with NestJS — a battle-tested Node.js framework used by enterprise applications. Data is stored in PostgreSQL via Supabase, the same database technology used by the Philippine government's e-services and major PH fintechs. Fully encrypted and backed up automatically.

Security & Reliability

Security is treated as a first-class concern, not an afterthought. The platform has undergone a full cybersecurity audit against the OWASP Top 10 — the industry standard checklist for web application vulnerabilities. Key protections include:

Authentication
Industry-standard JWT tokens with RS256 encryption. Email verification via OTP. Bot protection on registration via hCaptcha.
Payments
All payments processed by PayMongo — a BSP-regulated payment gateway. No card numbers are ever stored on Axon Tickets servers.
Data Protection
Rate limiting on all API endpoints. Input validation on every form. Security headers enforced. Database access requires authentication.

Scalability

The platform is designed to handle traffic spikes — which is critical for event launches when hundreds of buyers may try to purchase at the same time. Ticket reservation holds prevent double-booking during high-demand checkout. The cloud infrastructure scales automatically with load.

In plain terms: the platform is built to work reliably even when 200 people are trying to buy tickets at the same moment — a common scenario during early-bird ticket releases for popular events.

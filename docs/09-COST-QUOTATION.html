2. Assumptions & Methodology

Costing Assumptions

  • FX Rate: ₱56.00 / $1.00 (BSP indicative, May 2026). All PHP figures are estimates and fluctuate with exchange rate.
  • Developer Rate: $30/hour (mid-market Philippines full-stack developer, senior level, 3–5 YOE). Typical range: $15–$50/hour.
  • Maintenance Developer Rate: Same developer or equivalent. Part-time engagement model assumed.
  • Usage Model: "Growth Phase" assumes 1,000–10,000 registered users/month across 2–5 concurrent events. "Azure Scale" assumes 10,000+ users/month with SLA requirements.
  • Pricing Sources: All tool pricing sourced from official vendor pricing pages as of May 2026. SaaS prices are subject to change.
  • Azure Pricing: Based on Azure Calculator estimates for Southeast Asia region (Singapore). Actual costs vary with usage patterns.
  • Free Tier Limits: Listed limits are as of May 2026. Vendors may change free tier limits.

5.2 Upgrade Priority Order

First — When DB hits 400 MB

Upgrade Neon to Launch ($19/mo). This is the most likely first constraint.

Second — When emails exceed 3,000/month

Upgrade Resend to Pro ($20/mo). Typically triggered by ~300+ attendees × 10+ events/month.

Third — When team collaboration is needed

Upgrade Vercel to Pro ($20/mo/seat). Enables shared dashboards, log retention, preview URLs for QA review.

Fourth — When a hot event sells out in minutes

Add Cloudflare Pro + Turnstile ($20/mo). DDoS protection + invisible CAPTCHA on bundle checkouts.

Strategic — When enterprise SLAs are needed

Begin Azure migration. See Section 7 below.

7. Azure Cloud Migration (Scale-Up)

When Axon Tickets reaches enterprise scale — serving 10,000+ users/month, multiple organizers, uptime SLA requirements, or enterprise client contracts — a migration to Microsoft Azure (Southeast Asia region, Singapore) is recommended. Azure provides stronger SLAs, compliance certifications (ISO 27001, SOC 2), managed security services, and Philippine enterprise alignment.

Recommended Azure Region: Southeast Asia (Singapore) — closest to the Philippines with <30ms latency from major PH ISPs. Azure Philippines DC may become available; reassess when announced.

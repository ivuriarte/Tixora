Executive conclusion

Axon currently supports publishing events, email-code registration, manual payment review, digital ticket delivery, QR entry, administrative operations and business reporting. A separate protected test system and automated release checks are also in place. The sign-off applies only to the business areas, requirements, expected results and current completion status shown in this document.

How to read this document

Working now

The requirement is present in the current system and was confirmed during the review.

Working with limitations

Open or awaiting confirmation

The requirement is not yet available, or its live business configuration still needs evidence.

MVP-01

Identity, Access and User Profiles

Business value: Attendees and administrators can securely enter the correct experience while Axon protects account and administrative functions.

MVP-AUTH-01

Passwordless email access

Working now Essential Medium effort Current MVP
Business outcome: Enables the attendee to request and verify a one-time email code. Why it matters: They can enter registration without remembering a password.
What success looks like
  • If a valid email, when access is requested, then Axon creates or finds the account and sends a six-digit code.
  • If a valid unexpired code, when it is verified, then Axon signs the user in and creates a renewable session.
  • If five failed attempts, when another code is submitted, then the attempt is blocked and the current code is invalidated.
How this was assessed
Confirmed through a review of the current system and supporting records.
What must be in place
None
MVP-AUTH-02

Admin and organizer email/password authentication

Working with limitations Essential Medium effort Current MVP
Business outcome: Enables the administrator or organizer to sign in with their verified email address and password. Why it matters: They can securely access the administrative functions assigned to their account.
What success looks like
  • If an approved administrator or organizer account, when access is provisioned, then the account must have a verified email address and the required administrative permission.
  • If correct credentials for a verified administrator or organizer account, when login succeeds, then Axon signs the user in and routes them to the protected administrative experience.
  • If an ordinary attendee account, when email/password login succeeds, then administrative access remains unavailable unless the account has an approved administrative role.
  • If incorrect credentials or an unverified account, when login is attempted, then Axon denies administrative access and displays the appropriate verification or credential error.
How this was assessed
Confirmed through a review of the current system and supporting records.
What must be in place
None
What leadership should know: This email/password login is intended for Admin and Organizer access. Until event-scoped organizer roles are implemented, an organizer must be granted the existing administrative access level to enter the protected management experience.

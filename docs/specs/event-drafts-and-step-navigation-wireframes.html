Delete this draft?

"Improv Night Vol. 3" and its ticket tiers will be deleted. This can't be undone.

  • Setup progress uses the same rules as the publish checklist, so "2 of 5 ready" and "3 things left" never disagree.
  • Delete draft appears only on drafts that were never published (an event moved back to Draft after going on sale may have registrations, so it never shows this action). The server also refuses to delete an event that has registrations or orders.

Decisions · recorded Fri, Oct 2, 2026

What was approved

  1. Save a new event to the account once it has a valid title, venue and dates. No schema change and no placeholder data.
  2. Autosave drafts only. Published events keep an explicit Save changes button, now on every step.
  3. The server enforces the publish checklist whenever a draft becomes public, including via "Sold out".
  4. Audit rows stay append-only: one draft-save row per event, per person, per 15 minutes, with field names only.
  5. Skipped: refreshing the public link (slug) on title change, because it would break draft preview links already shared.
  6. Events with registrations or orders can't be deleted; cancel them instead. Today deleting removes them.
  7. Only platform admins can set the service fee and featured placement. Today organizers can change them.
  8. Ship in two releases: A (free navigation, checklist, save on every step, and the fee and deletion fixes), then B (server drafts and autosave).

1. Domain Recommendation

Primary Recommendation: axontickets.ph RECOMMENDED

Why .ph (Philippine TLD):

  • Immediately signals a Philippine-market product to attendees and organizers.
  • Stronger brand authority for a locally-focused ticketing platform vs a generic .com.
  • Lower registration competition than .com — high chance the exact name is available.
  • Required for Philippine DPA compliance: establishes clear Philippine data jurisdiction.

Registrar: DotPH (dotph.com) — the official .ph registry accredited registrar. Managed directly at the source.

Cost: ₱1,150–₱1,400 per year (standard .ph registration)

Fallback: axontickets.com FALLBACK

Register as a fallback if .ph is unavailable, or acquire as a redirect-only domain pointing to axontickets.ph. Prevents brand squatting.

Cost: ~$13–15/year (via Namecheap, Cloudflare Registrar, or Google Domains)

Action Required: Register axontickets.ph at dotph.com before Phase 0 CPD. DNS propagation takes up to 48 hours — register early so email deliverability is not a blocker for Phase 5 testing.

3. Email Service Provider — Resend

Why Resend

  • Already integrated in the codebase (apps/api/src/ uses Resend SDK).
  • Developer-first API — React Email templates supported natively.
  • Free tier: 3,000 emails/month, 100/day. Sufficient for MVP scale.
  • Built-in delivery analytics: open rate, click rate, bounce rate per email type.
  • Custom domain support on free tier (domain verification required).

Resend Plan Comparison

Daily Limit Risk: Resend free tier is capped at 100 emails/day. If a single event approves 150 registrations in one day, QR delivery will be throttled. Mitigation: Stagger bulk approvals across multiple days, or upgrade to Pro ($20/month) before any event with expected single-day approvals >100. Monitor in Resend dashboard.

DKIM Key: The CNAME value for DKIM is auto-generated by Resend after you add your domain in the Resend dashboard. Do not set it manually — copy the exact value Resend provides. It changes per account.

DNS Setup Steps (Ordered)

  1. Register axontickets.ph at DotPH.
  2. Log in to Resend dashboard → Domains → Add Domain → Enter: axontickets.ph
  3. Resend will display 3 DNS records to add (SPF TXT, DKIM CNAME, DMARC TXT). Copy exact values.
  4. In DotPH DNS management: add all 3 Resend records + Vercel A record + www CNAME.
  5. Wait for propagation (typically 5–30 minutes for .ph, max 48h).
  6. In Resend dashboard: click "Verify Domain". All 3 records must show green checkmarks.
  7. In Vercel: add axontickets.ph as custom domain for web project. Vercel will confirm A record.
  8. Update environment variable in API project: RESEND_FROM_ADDRESS=hello@axontickets.ph

6. Email Template Specifications

Registration Confirmation Email

  • Top: Axon Tickets logo + brand header (navy #1A3A5C, orange accent)
  • Body: "Hi [First Name], you're registered for [Event Name]!"
  • Details box: Event name, date/time, venue, tier name, attendee count
  • Reference number: Large, bold, monospace font — easy to copy
  • Instructions: "Next step: upload your payment proof" → orange CTA button linking to proof upload page
  • Payment section: Payment instructions text + payment QR image (if event has one)
  • Footer: "Questions? Reply to this email." + Philippine privacy notice (DPA 2012)

QR Delivery Email

  • Top: "You're Approved!" banner (green confirmation)
  • Body: "Hi [Attendee Name], your ticket for [Event Name] is confirmed."
  • QR code: Large QR code image (300×300px) embedded inline (base64 CID, not external URL — works in offline/airplane mode)
  • Ticket summary box: Event name, date, time, venue, tier, attendee name
  • Instructions: "Show this QR at the entrance. Screenshot or print it as backup."
  • CTA: "View My Registration" → status page link
  • Footer: Organizer contact information

Rejection Notice Email

  • Top: "Action Required" header (orange warning tone)
  • Body: "Hi [First Name], your payment proof for [Event Name] needs attention."
  • Rejection reason: Human-readable text from admin's selected reason preset (see UX Spec §microcopy)
  • CTA: Orange button "Re-upload Payment Proof" → links directly to upload screen for this registration
  • Support note: "If you believe this is an error, reply to this email."

Cancellation Notice Email

  • Top: "Registration Cancelled" header (neutral gray tone)
  • Body: Clear explanation — either "Early bird period ended" or "Event was cancelled by organizer"
  • CTA (if re-register possible): "Check if other tiers are still available" → event page link
  • Reference: Registration reference number for their records

7. Deliverability Strategy

Warm-up Plan

Resend handles sending reputation automatically on their infrastructure. For a new domain, the first 2 weeks of sending will have lower reputation. Follow this sequence:

  1. Week 1: Send to internal test emails only. Verify all DNS records pass. No bulk sends.
  2. Week 2: First real event registrations. Start small (<50 registrations). Monitor bounce rate in Resend dashboard.
  3. Week 3+: Normal operation. Bounce rate should be <2%. Spam complaints <0.1%.

Bounce Management

  • Resend automatically suppresses bounced addresses. Monitor in Resend dashboard → Suppressions.
  • Hard bounce rate >5% triggers deliverability review. Common cause: registrants entering invalid emails.
  • Mitigation: Email format validation at registration form. Consider adding email confirmation input (enter email twice) on the registration form to reduce typos.

11. Future Considerations

Receiving Replies (Post-MVP)

The MVP does not require a mailbox for incoming email. Attendees who reply to hello@ will get a bounce (no MX record). For post-MVP, add an MX record pointing to either:

  • Google Workspace (~$6/user/month) — full Gmail experience, professional email for the team
  • Zoho Mail (free up to 5 users) — free email hosting for small teams
  • Forwarder only (via DotPH or Cloudflare Email Routing) — forward hello@ to an existing personal Gmail, at zero cost
MVP Decision: Set up a simple email forwarder (DotPH email forwarding or Cloudflare Email Routing) to forward hello@axontickets.ph to the organizer's existing email. This allows attendees to reply and get a response without requiring a full mailbox setup. Cost: free.

Dedicated IP (Future Scale)

At >10,000 emails/month, consider Resend's dedicated IP option to ensure sending reputation is not affected by other Resend customers. Cost: contact Resend for pricing at that tier.

Email Analytics (Post-MVP)

Resend provides open rates and click rates per email type. Use these to:

  • Identify if QR delivery emails are being marked as spam (low open rate = deliverability issue)
  • Track unsubscribe rates per email type
  • A/B test subject lines for better attendee open rates on confirmation emails
